## 💻 Programs

This repository contains **8 practical programs** based on basic C++ programming and Object-Oriented Programming concepts.

### 01. Basic Data Types

Demonstrates the use of basic data types such as `int`, `char`, and `float` to store student information.

### 02. if-else

Demonstrates selection using an `if-else` statement to check whether a student has passed or failed.

### 03. Loop and Array

Demonstrates the use of arrays and a `for` loop to store and display marks of five students.

### 04. Functions

Demonstrates the creation and use of a function for performing addition.

### 05. Class and Object

Demonstrates the creation of a class and object to store and display student details.

### 06. Constructor and Destructor

Demonstrates automatic object initialization using a constructor and cleanup using a destructor.

### 07. Static Member

Demonstrates the use of a static data member to count the number of objects created.

### 08. Inline and Friend Function

Demonstrates an inline getter function and a friend function to access private data.
